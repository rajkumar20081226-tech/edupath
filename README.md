# EduPath

EduPath is an AI student tutor startup MVP.

## What it does
- Chat-based AI tutor for students
- Helps with homework and concept explanations
- Creates quick quizzes
- Supports revision planning
- Works without an OpenAI key using a local fallback reply system

## Run it

1. Install dependencies:

```bash
npm install
```

2. Add your environment key if you want OpenAI powered replies:

```bash
cp .env.example .env.local
```

3. Start the app:

```bash
npm run dev
```

4. Open in browser:

```text
http://localhost:3000
```

## Startup direction
This MVP can become:
- a student tutor app
- an exam prep platform
- a homework assistant subscription product
- a school/college AI learning platform
